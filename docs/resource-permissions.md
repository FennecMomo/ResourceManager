# 资源权限与设备身份（0.5.3）

在“我的发布”中选中分组，右侧点击“权限设置”。支持公开、私有和设备白名单；子分组默认继承上级，顶层默认公开。文件详情显示最终权限和来源。默认组也能设置权限，已有资源升级后仍为公开。

白名单选择已登记设备，显示昵称、本机备注、固定设备 ID 和最近地址。设备改昵称或 IP 不改变授权。白名单为空时没有远端设备能访问。删除设备会清理它在所有分组中的白名单条目，并在确认框显示影响的分组数量；以后重新连接不会恢复旧授权。

移动资源或分组后，新的目录和下载请求立即按目标位置的有效权限判断。已打开的下载流可能继续完成，已下载到对方电脑的内容不会收回。删除分组并将资源归入默认组时，资源随默认组权限生效。

私有分组不会出现在远端目录；如果子分组显式覆盖为公开，允许访问的子分组会作为根节点展示，不泄露隐藏父组名称。权限检查覆盖平面清单、分组清单、文件树、文件内容、Range 续传和局域网更新源。

## 自动信任与请求校验

每台设备在资料数据库保存自己的 P-256 身份密钥。首次连接自动信任对方公钥，不需要账号或配对确认。双方通过带随机数的签名握手确认各自持有私钥；已保存的设备公钥不允许静默更换，也不允许降级为无签名节点。移除设备时保留公钥绑定，避免用原 ID 冒名恢复信任。

后续每个请求独立签名，绑定发送方、接收方、HTTP 方法、路径与查询参数、正文摘要、Range / If-Range、时间和随机数。允许的时钟偏差为五分钟；随机数持久去重，进程重启后也不能重放。客户端自动刷新握手缓存；认证失败时只重新握手并重试一次，不反复提交业务操作。

新版通过校验后的设备身份读取白名单，不把来源 IP、正文中的设备 ID 或转发头当成授权凭据。当前未实现服务器代转身份，未来转发入口必须提供独立可验证的来源证明。旧版保留已登记 IP 的公开资源访问方式，不能读取白名单和私有资源；白名单设备需双方均升级至 0.5.3。

身份数据库随正常存储迁移一起复制，保留私钥、公钥绑定、权限及设备关联。系统时间偏差过大、资料身份损坏或同 ID 使用其他密钥时，连接会明确报身份校验失败。不会为了恢复连接自动清空信任或公开受限内容。

## 收藏状态与隐私

发布端记录经过身份验证的设备曾经看到的资源 ID。这样的资源撤销后可以告知该设备“已撤销”；权限被收回则返回“无权访问”。对从未有权看到的 ID，未知资源和受限资源返回一致的拒绝，不提供名称或存在性信息。旧版收藏在升级后尚未成功访问过资源时，也可能只能得到“无权访问”，不能据此判断资源是否仍存在。

本功能用于可信局域网，继续使用 HTTP。签名验证请求身份和完整性，不加密文件、聊天或响应内容，也不替代首次信任时的网络可信性。

## 验证

自动化测试覆盖继承与覆盖、移动、删除设备清理、相同 IP 下不同身份、旧版访问隔离、隐藏父组、已知 ID 越权下载、Range、权限撤回、资源撤销状态、冒用身份、篡改签名、重放与重启后的重放、更新源过滤及存储迁移。界面使用隔离资料离屏检查，不操作用户桌面。
