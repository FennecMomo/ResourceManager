# 聊天图片与复制（Windows 1.1.3）

文字气泡可以选择文本后按 Ctrl+C。右键“复制”会复制选中内容；没有选择时复制整段文字，保留换行。

在聊天输入框按 Ctrl+V 可以粘贴剪贴板图片。也可将 PNG、JPEG、GIF、BMP、TIFF 图片文件或位图直接拖入聊天区，使用私发副本发送。操作开始时固定收件设备和图片快照，切换会话不会改变接收人；发送不会公开发布图片，也不修改或删除拖入的原文件。普通文字粘贴仍编辑草稿，普通文件和文件夹仍保留引用/副本选择。

快捷图片单张最多 20 MiB，剪贴板位图最多 1600 万像素，一次最多 16 张图片。其他格式和较大文件可通过“发送资源”作为普通文件发送。GIF 和 TIFF 的缩略图及剪贴板图像使用第一帧；另存为保留原文件内容。

图片消息在呈现到聊天页后后台加载缩略图。右键“复制图像”读取原始分辨率的图像数据写入剪贴板；“另存为…”选择保存位置，同名文件自动编号，不覆盖原文件。加载失败显示占位，仍可另存为。两端沿原有资源协议通信，旧版接收端会继续按文件附件显示。

收到的图片只通过既有带身份签名和接收方检查的资源通道读取。预览不创建正式下载任务，也不把自动获取预览当成用户完成附件下载；显式另存为沿用原下载与回执逻辑。聊天传输的原有加密和联网边界保持一致。

接收端预览缓存位于资料目录的 `chat-image-cache`，有总量上限。清空本机会话会清理该会话预览缓存；原图片、其他会话及对方已经保存的文件不会被删除。粘贴位图生成的临时 PNG 在发送准备结束时清理，退出会等待准备任务收尾；准备期间本机控制通道拒绝后台换版。

自动检查使用隔离资料、带签名的本机测试节点和剪贴板/保存位置替身，不读写用户正在使用的剪贴板，也不操作桌面窗口。真实图片软件的剪贴板互通仍可通过日常使用反馈验证。
