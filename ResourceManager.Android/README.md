# ResourceManager Android 0.1.1 测试版

最低 Android 10 / API 29。Android 版本独立于 Windows，本轮配套 Windows 0.7.5 的并行发现修复。

## 使用

1. 安装 `ResourceManager-Android-0.1.1-test.apk`，按系统提示允许当前安装来源。此包为开发测试签名，尚非应用商店发布包。
2. 手机和电脑连接同一可互访的局域网。在手机点“开启”，电脑也需保持共享运行。共享时会显示常驻通知，可从通知或应用停止。
3. 在“设备”刷新；广播被路由器隔离时填写电脑 IP 和端口（默认 `37642`）手动连接。离线设备记录不会因一次超时消失。
4. 在“我的发布”选择文件或目录。系统选择器负责授予访问权；内置文件浏览器可添加授权目录、进入子目录、按名称/图片/视频/音频/文档筛选、多选发布。默认引用原文件，也可选择复制到应用内。其他 App 分享进入的文件先选择接收会话，确认后复制私发。
5. 分组可设公开、仅自己、设备白名单。访问限制作用于每次目录、元数据和下载请求。私发副本不出现在公开资源中。
6. 浏览设备资源，按名称/备注、文件或文件夹、最小大小检索。目录预览保留空目录；下载在“传输”查看，可暂停、继续。完成后可“保存到…”或通过系统分享发送给微信、QQ、飞书等已安装且支持对应文件类型的应用。文件夹分享为 ZIP。
7. 在“消息”进入会话，或从设备页开始聊天，可发文字、已发布资源卡片或私发文件/目录。输入框为 1–5 行；“对方已接收”表示消息回执，不表示对方已阅读或下载附件。暂不可达时排队重试，超过 7 天停止重试。
8. 允许通知后，新消息与定向资源提醒显示通知；点通知进入对应会话。拒绝通知不影响消息记录，可在设置重新开启。

## 首版边界

- 本版提供局域网对等节点；服务器绑定、跨公网中继、推送唤醒、自动更新不在本次首版范围。
- 共享需由用户主动开启。停止共享或网络不可达时手机离线。共享期使用前台服务、CPU 唤醒锁与组播锁，支持 Wi-Fi 重连和系统允许的服务重建。在“设置 → 后台运行”查看电池优化状态并打开标准系统设置；持续共享会增加耗电，Doze 未豁免时系统仍可能限制联网。没有厂商或机型专属逻辑。
- 点对点 HTTP 使用身份签名、固定密钥与重放防护，内容不加密，沿用现有桌面协议。
- 引用发布依赖系统 URI 授权和源文件存在；授权失效会显示不可用。无法获得稳定长度的提供器请使用复制发布；没有可靠修改时间的源不提供续传 ETag。
- 下载先存应用私有区，确认完成再导出；文件版本改变时回退整文件下载。现有 P2P 未提供通用 SHA-256 元数据接口，不能把长度/ETag 校验称为端到端哈希校验。
- 系统分享是 Android 通用协议，具体第三方应用是否接受该文件类型取决于对方版本。本轮没有在真实微信、QQ、飞书账号中发送文件。
- 本版关闭备份与设备迁移，以免恢复资料库却丢失不可导出的设备身份密钥。卸载会删除应用私有资源、消息和下载缓存；需要保留的文件先导出。

## 构建

采用 Kotlin 2.2.21、Compose、SQLite、Android Keystore、OkHttp、Ktor CIO；Gradle 8.13 / AGP 8.13.2，compile/target API 36。依赖锁定具体版本，不使用动态版本。Gradle wrapper 固定官方 SHA-256。

需要 JDK 17、Android SDK platform 36、build-tools 35.0.0、platform-tools。项目工具缓存放在忽略的 `.tools/android`，不提交 SDK、密钥或构建产物。

```powershell
# 仓库根目录；可传 -JavaHome 和 -SdkRoot，或配置对应环境变量
./tools/android-build.ps1 -Package
# 仅用于明确指定的隔离模拟器/测试手机，安装 APK 并运行设备测试
./tools/android-build.ps1 -DeviceTests -DeviceSerial emulator-5580
```

常规 Gradle 入口为 `ResourceManager.Android/gradlew.bat`，任务 `:protocol:test :app:assembleDebug :app:lintDebug`。测试包额外使用 `:app:assembleDebugAndroidTest`。设备测试专用 DocumentsProvider 只在 instrumentation APK 中，不进入客户端 APK。

完整设计和实施验证记录见仓库 `docs/design/android/`。测试与互通命令见 `validation.md`。
