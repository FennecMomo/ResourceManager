# 设置页隔离回归

在仓库根目录运行：

```powershell
dotnet run --project tools/SettingsChecks/SettingsChecks.csproj
```

运行实际 WPF 主窗口及切页事件，但从不显示窗口、托盘图标或确认弹窗。
数据库使用 `dist/settings-checks/data-<随机 ID>`；注册表、网络应用和确认选择使用注入的替代实现。
成功输出各项 PASS，失败以非零退出码结束。渲染结果保存在同目录的 PNG 中，来自离屏控件，不截取桌面。

覆盖保存/放弃/继续编辑、还原原值、非法昵称和端口、自启保存失败、网络应用失败、保存期间再次编辑和切页、路由器草稿保存与刷新保护、本机退出保护，以及两种窗口尺寸的保存按钮固定位置。
